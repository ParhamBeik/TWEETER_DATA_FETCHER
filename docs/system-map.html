    The core constraint

    One X rate budget, three collectors

    X allows 50 UserTweets requests per 15 minutes for the single shared session. Live polling and the archive walk spend it together, so the archive walk always leaves a reserve for live. That reserve is computed every run from how many accounts are due (fetching.accounts.archive_quota_floor); it is not a setting.

    live reserve
    archive walk (≤ 25 pages / tick)

    Illustrative split. The real ratio moves every 5 minutes with the live due-set.

    How far back each fetch reaches:

    effective_cutoff = min(now − configured_window, floor(fetch_watermark))

    Historical floors the watermark to the start of the Tehran day, live to the hour. Watermarks advance only after a successful run, so a failed run is retried from the same point. Overlap is deduplicated on author_id:tweet_id.

    Priority tiers (engine/config.py; new accounts start at tier 7). Each account's actual poll interval is its measured median posting gap, clamped into its tier's band and recomputed daily.
